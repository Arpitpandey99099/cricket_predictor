# Cricket Player Performance Predictor

**Overview:** 
A command-line Python application that ingests T20 cricket statistics and uses Machine Learning to predict upcoming player performance.

**Features:**
* Interactive CLI menu
* CSV data ingestion and cleaning
* Franchise statistics calculation
* Scikit-Learn Random Forest classification

**Technologies Used:** 
Python, Pandas, Scikit-Learn

**Installation & Execution:**
1. Clone this repository to your local machine.
2. Open the terminal in the project directory.
3. Create a virtual environment: `python -m venv venv`
4. Activate the environment: `.\venv\Scripts\activate` (Windows)
5. Install required dependencies: `pip install pandas scikit-learn`
6. Run the application: `python main.py`

**Instructions for Testing:**
When the menu appears, press `1` to load the dataset, `2` to view calculated team stats, and `3` to run the Machine Learning model on the current roster.
